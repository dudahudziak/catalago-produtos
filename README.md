# Catálogo de Produtos (React + Vite)

Aplicação de estudo com componentes, props, state, formulário controlado e useEffect.

## Como rodar
```
npm install
npm run dev
```

## Estrutura
```
src/
├── components/   ProdutoCard.jsx, FormProduto.jsx
├── pages/        Home.jsx
├── data/         produtos.js (dados mockados)
├── assets/       imagens
├── App.jsx
├── main.jsx
└── index.css
```
